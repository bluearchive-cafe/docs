# 使用配置

汉化版客户端首次登录默认不会开启任何汉化功能，并会从官方下载所有资源，需要使用控制面板手动启用汉化功能。

## 汉化功能说明

> [!NOTE]
> 更改汉化设置需要重启游戏，并重新下载部分游戏资源。

- 文本汉化（200 MB 重新下载）

  此选项控制绝大多数游戏文本语言，如客户端启用汉化后出现异常可尝试暂时关闭文本汉化。

- 主线中配（1.5 GB 新增下载）

  此选项控制主线故事中的配音语言，作用范围仅限主线故事，不包括大厅语音、活动语音、战斗语音等场景。

- 图像视频（1~2 GB 重新下载）

  此选项控制游戏内图像与视频资源，作用范围包括主线故事、活动剧情、战斗贴图、界面图标等场景。

## 公告内控制面板

> [!NOTE]
> 公告内控制面板提供了一种快速便捷且一键即可更改汉化设置的方式。

> [!TIP]
> 在标题界面点击左下角 `公告` 按钮，或在游戏大厅点击左上角 `公告` 按钮，即可进入公告并在控制面板内更改汉化设置。

> [!IMPORTANT]
> 此处所述的 UID 并非游戏账号信息内所显示的纯数字 UID，而是汉化服务器为每个客户端生成的唯一 UID，用于保存每个客户端的汉化功能设置，格式为八位大写字母。

若公告内控制面板使用出现异常，可点击公告内的 `异常通知` 标签页，左侧会显示当前 UID，可以使用此 UID 访问浏览器控制面板，建议保存 UID 以备用。

## 浏览器控制面板

> [!NOTE]
> 浏览器控制面板提供了一种无需进入客户端即可更改汉化设置的方式。

> [!TIP]
> 首次进入游戏时会有弹窗提醒，此时点击 `前往` 即可跳转到对应自己 UID 的浏览器控制面板，建议保存网页链接以备用。

> [!IMPORTANT]
> 此处所述的 UID 并非游戏账号信息内所显示的纯数字 UID，而是汉化服务器为每个客户端生成的唯一 UID，用于保存每个客户端的汉化功能设置，格式为八位大写字母。

要访问浏览器控制面板，需要先在公告内控制面板内复制链接，或在 `异常通知` 栏中获得自己的 UID，然后将 UID 拼接到以下 URL 之后：
```
https://dash.bluearchive.cafe/
```
