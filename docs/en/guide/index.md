# Usage and Configuration <span id="使用配置"></span> {#usage-and-configuration}

On first login, the Chinese localization client leaves all localization features disabled and downloads the original resources from the official servers. Enable the features you want in the control panel.

## Localization features <span id="汉化功能说明"></span> {#localization-features}

> [!NOTE]
> Changing localization settings requires restarting the game and downloading some resources again.

- **Translated text** (about 200 MB to download again): changes most game text to Chinese. If the client behaves unexpectedly, try temporarily disabling this option.
- **Chinese main story voices** (about 1.5 GB of additional downloads): changes voices in the main story only. Lobby, event, and battle voices are not included.
- **Images and videos** (about 1–2 GB to download again): changes visual resources in the main story, event stories, battle textures, interface icons, and other areas.

## In-game control panel <span id="公告内控制面板"></span> {#in-game-control-panel}

The control panel inside the notices lets you change localization settings directly.

Open **Notices** from the bottom left of the title screen or the top left of the lobby, then use the embedded control panel.

> [!IMPORTANT]
> The UID here is **not** the numeric UID in your game account information. It is a unique identifier generated by the localization server for each client to store its settings. It consists of eight uppercase letters.

If the embedded control panel fails, open the **Error Notifications** (`异常通知`) tab in the notices. Your UID appears on the left. Save it so you can use the browser control panel later.

## Browser control panel <span id="浏览器控制面板"></span> {#browser-control-panel}

The browser control panel lets you change settings without opening the game. On your first visit to the game, choose **Go** (`前往`) in the prompt to open your personalized panel. Bookmark the page for later use.

You can also copy the link from the in-game control panel, or obtain your eight-letter UID from the Error Notifications tab and append it to:

```text
https://dash.bluearchive.cafe/
```

Use the localization UID described above, not your numeric game account UID.
